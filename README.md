# HR Management System for GCR Ratings

## Overview
This repository contains the development of a **Salesforce-based HR Management System** for **GCR Ratings – An Affiliate of Moody's**.

The project is being developed by **Stranger Strings** as part of our software development coursework. The system aims to streamline HR processes by providing dedicated portals for employees and HR administrators.

## Project Objectives

The HR Management System will allow:

### Employee Portal
- Manage personal profile
- Apply for leave
- View leave balances
- Access HR documents
- Submit training requests

### HR/Admin Portal
- Manage employee records
- Manage departments
- Approve or reject leave requests
- Manage training records
- View reports and dashboards
